# LuneCore
LuneCore is a rudimentary Scala core plugin made for my other plugins including [ShowOff](https://github.com/yukkuricraft/showoff). LuneCore provides some basic helper and library methods while also adding small miscellaneous features that I didn't think deserved their own bespoke plugin.

LuneCore is written in Scala and built with sbt for Paper in Minecraft Java 1.21.4+.

*See the [wiki](https://github.com/LunaPixu/LuneCore/wiki) for more info.*
